# Security

Report suspected vulnerabilities privately to support@sendrepute.com. Include
affected version, impact and a minimal redacted reproduction. Do not open public
issues with exploit details, credentials, customer messages or personal data.
We will coordinate a fix and disclosure; no response-time guarantee is implied.

Use the latest reviewed release. Version 0.1.x is the current supported source
line; older revisions may not receive fixes. Keep API keys server-side, scoped
and rotated. Do not log request bodies or bearer headers. Classification and AI
operations can be billed; obtain explicit consent and bound retries. Test
blocking and failure policies before applying them to transactional email.
